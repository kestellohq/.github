# kestellohq/.github

The kestellohq organization's profile and its default community files.

- `profile/README.md` is the page shown on [github.com/kestellohq](https://github.com/kestellohq). Its banners come from the Kestello brand kit (the open graph images, cropped).
- `SECURITY.md` and `CODE_OF_CONDUCT.md` apply to every kestellohq repository that has none of its own.

Changes go through a pull request, like in every other kestellohq repository.
