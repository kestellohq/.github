# Security policy

This policy applies to every kestellohq repository that has no security policy of its own.

## Reporting a vulnerability

**Please don't open a public issue, discussion or pull request.**

Report it privately through GitHub: open the affected repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers see it. When you are not sure which repository is affected, report it on [cms](https://github.com/kestellohq/cms/security/advisories/new).

Include the versions involved, what an attacker can do and what they need first, and the steps or a proof of concept, kept to the minimum that shows the problem.

## What happens next

We confirm a report within 3 working days, and tell you within 10 working days whether we can reproduce it and how serious we think it is. Before a fix ships we agree a disclosure date with you, normally within 90 days of the report, and the advisory credits you unless you'd rather it didn't.

The full policy, with supported versions and scope, is the [Kestello security policy](https://github.com/kestellohq/cms/blob/develop/SECURITY.md).
